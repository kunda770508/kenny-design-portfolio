WEB DESIGNER / UI & UX

你好，我是江昆達，叫我 Kenny 就好。
十年來，持續在視覺、內容與互動之間，
尋找讓網站更清楚、更有感的方式。

我重視第一眼的品牌印象，也在意資訊如何被閱讀、操作如何被理解，以及設計如何在不同裝置上順利落地。

好的設計，讓品牌保有個性，
也讓使用者自在地找到下一步。

Visual & Web Design

以字體、色彩與版面節奏，建立有辨識度的品牌網站，讓內容有清楚的主次，也有值得停留的畫面。

品牌視覺 / 網頁設計 / 響應式版型
02

UI / UX Thinking

梳理資訊層級與操作路徑，思考每個區塊與互動的目的，讓複雜的內容變得容易理解。

資訊層級 / 操作流程 / 介面設計
03

Design to Build

理解實作限制，與團隊對齊需求、畫面及互動細節，讓設計從提案延續到真實的使用體驗。

設計落地 / 跨裝置調整 / 團隊協作

MY APPROACH

不只是一張畫面，
而是一段完整體驗。

  1. 01 / UNDERSTAND

    理解品牌與需求

    釐清目標、內容與使用情境，找到設計要回答的問題。

  2. 02 / DESIGN

    整理資訊與視覺

    建立層級與版面節奏，讓品牌個性和操作直覺一起成立。

  3. 03 / REFINE

    對齊實作與細節

    檢視響應式、互動與內容呈現，持續調整真正被使用的畫面。
